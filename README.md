# Посмотри в окно

Проектная работа Яндекс Практикума: стилизация готового приложения, которое показывает видео из окон разных городов.

Ссылка на репозиторий: https://github.com/lev1n27/posmotri-v-okno-ad

## Что сделано

- Лейаут страницы на флексбоксе: блок с видео, форма поиска, заголовок и список карточек.
- Видео и превью подогнаны под размеры через `object-fit`.
- Кастомные чекбоксы на псевдоэлементах и стилизованное текстовое поле.
- Состояния `:hover`, `:active` и `:focus-visible` у кнопок, чекбоксов, поля ввода и карточек.
- Обрезка длинных заголовков многоточием и описаний через `line-clamp`.
- Прелоадеры позиционируются внутри блока с видео и списка карточек.

## Как открыть

Откройте `index.html` через локальный сервер, например расширение Live Server. Макет рассчитан на ширину экрана от 1200px.
